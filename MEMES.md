# PRIOR · MEME PROMPT DECK

Gemini-ready prompts. Each block: scene → caption → style note.
Voice: dry, surgical, on-edge. The image carries the receipt; the caption lands the knife.
Aspect ratio default: 1:1 for X. Use 16:9 for cinematic / banner pulls.

Style baseline (use across the deck unless noted):
> moody analog film grain, muted desaturated palette with selective amber accents, surveillance-camera aesthetic, slight VHS scanlines, low contrast except for one focal element, photographic realism with documentary feel, 35mm lens look, no logos, no watermarks, no text artifacts inside the image (caption is overlaid separately).

## NOTES FOR USE

- **Caption placement**: lower third, white sans-serif (Helvetica / Inter), 90% opacity, no drop shadow. The image should breathe.
- **Watermark**: small `priorprotocol.fun` lower-right corner, 40% opacity. No emoji.
- **Posting cadence**: don't carpet-bomb. one meme per 3-4 posts max. let the bot's longform set up the meme, not the other way around.
- **Tone check**: if a meme makes you laugh and then makes you uneasy 5 seconds later, it's right. if it just makes you laugh, it's not PRIOR enough.
- **Retire timer**: each meme has a 3-week shelf life. archive it after, do not recycle inside the window.
- **Format pairings that hit**:
  - Dialogue scene + stat meme back-to-back (#49 → #55)
  - Pattern meme on Sunday (long-form thinking day), specific receipt on Monday (news cycle)
  - Character meme (#41-#48) when a major scandal breaks — establish PRIOR's voice in the moment
- **Don't generate**: anything that names a private individual not already public-record (no doxxing), anything that uses real death imagery as punchline, anything with slurs (will tank credibility within an hour).
